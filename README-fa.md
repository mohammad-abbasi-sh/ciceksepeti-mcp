# ciceksepeti-mcp 🇹🇷

> ⚠️ **وضعیت: دچار اختلال (۲۰۲۶-۱۱-۱۰)** — سایت ciceksepeti.com در حال حاضر دسترسی خودکار را مسدود می‌کند: اتصال قطع یا درخواست رد می‌شود (۴۰۳). همه‌ی ابزارها خطای واضح «مسدود» برمی‌گردانند. وضعیت زنده را با `ciceksepeti_health` بررسی کنید.


mcp-name: io.github.mohammad-abbasi-sh/ciceksepeti-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای **ciceksepeti.com**، مارکت‌پلیس
پیشرو در تحویل گل و هدیه در ترکیه — جست‌وجو در هزاران دسته‌گل، گیاه و
هدیه، خواندن جزئیات کالا (قیمت، قیمت لیست، موجودی، امتیاز، فروشنده،
دسته)، خواندن نظرهای مشتریان، مرور ۸۹ دسته‌ی گل/گیاه/هدیه، و گرفتن آمار
قیمت (کمترین / میانه / میانگین / بیشترین) برای هر جست‌وجو.

> ساخته‌ی محمد عباسی در چارچوب «کارخانه‌ی MCP ترکیه» (به سبک سپهر). هیچ
> وابستگی‌ای به ciceksepeti.com ندارد.

## برای ایجنت‌های هوش مصنوعی

به پیکربندی MCP client خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "ciceksepeti": {
      "command": "uvx",
      "args": ["ciceksepeti-mcp==0.1.0"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m ciceksepeti_mcp.server`
(نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|-------|
| `ciceksepeti_search` | جست‌وجوی گل و هدیه با کلیدواژه — `query` (مثل «kırmızı gül» یا «orkide»)، `sort` (‏«relevance» / ‏«price_asc» / ‏«price_desc»)، `limit` از ۱ تا ۲۴، `page` از ۱؛ برمی‌گرداند: عنوان، قیمت به لیر، قیمت لیست، تعداد نظر، امتیاز ستاره‌ای (۰ تا ۵)، یادداشت تحویل، آدرس، عکس |
| `ciceksepeti_product_detail` | جزئیات یک کالا (`product` = آدرس کامل یا مسیر ختم‌شده به «-at<id>»): نام، برند، قیمت به لیر، وضعیت موجودی، امتیاز، تعداد نظر، فروشنده، مسیر دسته، توضیح، عکس‌ها |
| `ciceksepeti_list_categories` | ۸۹ دسته‌ی گل/گیاه/هدیه: نام ترکی، آدرس، اسلاگ |
| `ciceksepeti_price_stats` | آمار قیمت برای یک جست‌وجو: تعداد، کمترین / میانه / میانگین / بیشترین قیمت (لیر) |
| `ciceksepeti_product_reviews` | نظرهای اخیر مشتریان برای یک کالا: نویسنده، امتیاز ستاره‌ای و تاریخ (سایت ciceksepeti متن نظرها را سمت سرور رندر نمی‌کند) |

نمونه‌ی خروجی (`ciceksepeti_search` / ‏«gül»):

```json
{"query": "gül", "count": 10, "products": [
  {"title": "13'lü Kırmızı Gül Buketi",
   "url": "https://www.ciceksepeti.com/ask-sembolu-13-kirmizi-gul-buketi-at4033",
   "product_id": "4275287", "price_try": 899.99,
   "original_price_try": 1149.0, "review_count": 26946, "rating": 4,
   "delivery": "Aynı Gün Ücretsiz Teslimat"}, …]}
```

## چطور کار می‌کند؟

سایت ciceksepeti.com به کلاینت‌های HTTP ساده جواب می‌دهد؛ با این حال
لایه‌ی انتقال از جعل TLS کروم (`curl-cffi`، ‏`chrome120`) استفاده می‌کند
تا یک بررسی ربات سخت‌گیرانه‌تر سرور را از کار نیندازد. API عمومی JSON
ندارد — داده‌ها از HTML رندرشده‌ی سمت سرور می‌آیند: صفحه‌های جست‌وجو
۳۰ باکس کالا در هر صفحه دارند (عنوان، قیمت، تعداد نظر، امتیاز ستاره‌ای،
یادداشت تحویل)، صفحه‌های کالا JSON-LD از نوع Product به‌همراه مسیر دسته
(breadcrumb)، و صفحه‌ی اصلی ۸۹ لینک دسته دارد. مرتب‌سازی با پارامتر
آدرس است (`orderby=2` گران‌به‌ارزان، `orderby=3` ارزان‌به‌گران — به‌صورت
زنده تأیید شده) و صفحه‌بندی با `page=N` (زنده تأیید شده). درخواست‌ها با
فاصله‌ی حدود ۰٫۸ ثانیه فرستاده می‌شوند؛ همه‌چیز فقط‌خواندنی است، بدون
لاگین و بدون کلید API.

## نصب

```bash
uvx ciceksepeti-mcp==0.1.0        # اجرای مستقیم (نیازمند uv)
# یا
pip install ciceksepeti-mcp==0.1.0
ciceksepeti-mcp    # اجرای سرور MCP روی stdio
```

## تست‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

تست‌های آفلاین روی نمونه‌های ضبط‌شده از صفحه‌های واقعی اجرا می‌شوند
(دریافت‌شده در ۲۰۲۶-۱۱-۰۶)؛ تست‌های زنده به ciceksepeti.com وصل می‌شوند.
